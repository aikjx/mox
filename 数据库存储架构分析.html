项目根：D:\a10\aikjx\gitcode\infotopograph · Rust workspace 3.0.0-ai-powered · 分析日期：2026-09-01

一、结论速览

当前主存储为 SQLite（嵌入式，rusqlite bundled），默认库文件 mox.db； 知识图谱域另用 RocksDB（KV，可选 feature）； Redis 作为缓存独立部署（docker-compose）。 对 PostgreSQL / MySQL：已通过 sqlx 0.8（postgres/mysql feature） 与 sea-query（backend-postgres/backend-mysql） 完成接线， 用环境变量 MOX_BACKEND=postgres|mysql 在编译期/运行期切换。 即：SQLite / PostgreSQL / MySQL 三种关系型后端均兼容，SQLite 为默认。
