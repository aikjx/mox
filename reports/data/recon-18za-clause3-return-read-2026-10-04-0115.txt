## 三、判决（三条，逐条现量）
⑴ §1.8z 那三张图像（真语料／if 守卫／嵌套 for）对第三条款**全部无感**：撤前撤后逐档位逐说明相同。
    实测无感名单 ['真语料', 'if 守卫', '嵌套 for'] ⇒ 「那三张的覆盖面」不许记到第三条款名下（针＝变异体41·乙）。
⑵ 第三条款的牙只在第四张「计数键改名」：基线 ['name-only'] → 撤③ ['pair']。
    基线说明：计数键 tally 不在 return 读的 agg 键集 ['violations'] 里
    撤③说明：明细 agg[details]（append@153）的计数键 tally 被 return 读
    ⇒ 失效方向是**静默假阳且说明撒谎**：升成 pair 之后那句「被 return 读」是假的，
      交出去的是 return 里那个旧键的数，而累加写进了改名后的键（针＝变异体41·甲）。
⑶ 第五张「return 摘键」两侧都**无判决**，成因不在第三条款而在入口筛：
    真语料入口筛 ['driven']，摘掉 return 里那条 agg["violations"] 之后变 ['blind']（本函数内此后不碰累加器）。
    ⇒ 第三条款只有一条**窄走廊**可达：宿主名仍出现在 return 里（入口筛才判 driven），
      而配对到的计数键不是 return 读的那个。把宿主读整条摘掉时站点退成 blind 档，
      那一格属 blind 的账；空判决的成因点名到入口筛，不许读成「第三条款没牙」（针＝变异体41·丙）。
