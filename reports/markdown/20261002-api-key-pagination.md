# 凭证分页、状态和低代码契约归一化

2026-10-02。架构与接口权威见 [IAM 凭证契约](../../docs/modules/iam/API-KEYS.md)。

凭证列表从全量数组改为有界分页对象，默认每页 20、最多 100。按可信租户过滤，COUNT/单页读取同事务；复合索引支持稳定排序。外部数组调用者必须迁移，没有静默全量兜底。资格状态来自真实数据库，过期判断与鉴权共用函数，不把配置资格当作鉴权或业务执行成功。

两种前端入口共用分页响应校验和状态标签。修复低代码提交旧 read/write/admin 而被后端拒绝的问题；创建使用真实有效期及回执。引擎增加身份边界、过期异步响应保护、确认后执行作用域保护、错误清空及销毁保护。历史隔离测试同步接口形状及真实 Pinia，不作为业务成功证据；新增前端契约测试用 Node 标准库，不替换业务服务。

新增真实 SQLite/JWT/TCP 测试逐页验证 130 条同租户凭证、跨租户排除、同时间戳排序、末页及超大页号、非法参数、六种不可用配置、停用租户拒绝，以及 EXPLAIN QUERY PLAN 使用复合索引。

最终结果见 [检查记录](../data/20261002-api-key-pagination/summary.json)。未完成浏览器完整登录流程、跨页并发导出一致性、深页吞吐、历史密钥迁移、动态 scopes 或跨主机验收。旧警告保留，不声明全系统已完成。

21 项 Rust 测试（19 项真实业务/HTTP/持久化及 2 项 IAM core）、4 项无业务替身的 Node 契约测试、1 项接口注册测试通过；前端构建、Clippy、模块化、locale、端口、文档链接、限定格式及 diff 门禁通过。台账同时纠正 IAM 与消息模块的权威链接。保留 215 条文档路径提示、284 条端口警告及已有构建/Clippy 提示。
