# 分项竞品核验与知识查询优化

竞品设计权威为 docs/modules/resource-knowledge/COMPETITIVE-DESIGN.md，核验日期 2026-10-01。已读取 Dify、Glean、Azure AI Search、Nextcloud 官方资料并分别映射知识流水线、源权限/删除、查询授权和跨出口规则。Azure 部分能力为 preview，Nextcloud latest 指向 upcoming 36；未执行这些产品的实机、付费方案或性能测试，也不宣称综合排名或超过竞品。

## 开发与测量

统计/标签共享一次当前主源扫描；查询不写 KV、不缓存 ACL。统计从可见摘要聚合标签和 JSON 逻辑字节，不逐文档 HEAD。另一个状态实例撤权后，原读取实例的新请求仍按主源拒绝。写端兼容派生索引继续保留；大规模事务索引仍待完成。

受控样本为本机 FS、12 份 JSON 文档、15 次顺序统计调用：对象 GET 720 → 180，HEAD 180 → 0，LIST 45 → 15。GET 次数减少 75%。观察到服务统计调用中位数 109.312 ms → 31.603 ms，仅为该本地样本，不是 HTTP 全链路 SLO、并发容量或竞品性能结论。CI 检查对象操作预算及权限新鲜度，不按绝对耗时判定。

检索新增 document_id/version/field/字符半开区间引用；原文含 İ、中文、emoji 时可安全定位，并从历史版本重建片段。正文未命中时使用版本化标题，未版本化生成摘要不作为稳定来源。空白/超过 512 字符查询和不在 1–100 的 limit 拒绝，排名同分以 ID 稳定排序。

知识库包 32 项 Rust 测试及 36 项前端测试通过，1 项既有 Rust 测试忽略。知识库包 Clippy、前端模块化门禁和文档链接检查通过，仍有存量告警。6 张流程图语法通过；文档盘点自检和一致性检查通过。未执行本轮前端构建重测，因为前端代码没有新修改，上轮构建证据保持原日期。

网关集成验收未通过：专家联盟共享状态正在迁移为租户分区，初次回归出现调用方未同步的编译错误，网关身份/对话测试尚未运行，联合 Clippy 失败。2026-10-02 复核发现这些文件仍有外部同步写入，因此保留改动，避免覆盖；不能把已通过的知识库测试计作网关或全工作区验收。错误归并及后续复测以同目录数据证据为准。
