# 收藏幂等回执与真实前后端联调

日期：2026-10-03。范围：收藏逻辑请求、回执持久化、客户端未知结果重试和身份隔离。没有宣称所有功能已完成或数学上的“最优”。

回执与收藏变化同事务提交；重复键重放原结果和首次时间，同键不同专家返回 409；作用域绑定认证租户及真实用户。重放查询当前状态，镜像及前端使用 current_favorite，避免旧结果覆盖后续操作。回执写入失败整体回滚，不产生半完成状态。

前端生成 UUID 并在同一逻辑操作的自动、手动重试中保留。未知失败留存尝试并给出重试提示；成功或明确拒绝才释放。退出/切换身份清除本地投影，令牌刷新保留同一用户的未确认操作；旧响应不得回填。现有 API、store 和响应归一化沿用原模块出口，未再建并行实现。

真实验证使用 12 个独立 SQLite 连接、实际回执触发器故障、真实 TCP 和生产 JWT/路由。额外运行实际 Vue/Pinia store 与 Axios，经转发生产 Rust 路由的 TCP 故障代理验证：后端提交后响应丢失、自动重试耗尽后的手动重试、后续新操作和令牌刷新。代理只转发真实业务响应并断开网络，不替换服务实现。没有新增 mock；历史服务替身测试不计为真实链路证明。

最终命令、退出码、源码指纹和未验收范围见 [summary.json](../data/20261003-favorite-idempotency/summary.json)。真实 store 探针由 `MOX_FAVORITE_FRONTEND_PROBE` 显式启用，普通 cargo 测试不自动声称该探针已执行。[权威契约](../../docs/expert-alliance/22-expert-object-contract.md) 增加 EA-OBJ-08/09 和恢复序列图。

最终通过：6 项仓储测试、1 项真实 HTTP 测试（再次启用实际 store 联调探针）、120 项现有契约检查、3 项纯请求契约测试；前端构建与相关门禁通过。原源码锚点因其他工作新增代码而漂移，已按实际定义位置更新，原失败日志保留。

剩余：刷新页面后的持久尝试恢复、收藏权威读接口、回执保留与清理、跨主机部署、真实浏览器页面和远程 CI 仍需开发/验证。其他功能模块沿用 26 模块/78 需求台账逐项验收；本轮不以局部通过替代整个平台交付。
