## 一、未实施的架构改进建议（按优先级排序）

### P0 — 高优先级（建议下一迭代实施）

#### 1. 新增 FormDialog.vue 通用组件
- **背景**：14 个页面重复实现「el-dialog + el-form + 校验 + 提交 loading」模式
- **收益**：减少约 200 行重复代码，统一表单弹窗交互体验
- **实现成本**：低（约 80 行代码）
- **API 设计**：
  ```js
  props: { title, visible, fields: Array, loading: Boolean, width: String }
  emits: { submit(values), close }
  ```

#### 2. 统一 project 状态管理（消除 project.store.js 与 projectContext.js 重叠）
- **背景**：两处维护同一份 `currentProject` / `projects` 状态，可能导致不同步
- **建议**：保留 `projectContext.js`（composable 模式更灵活），将 `project.store.js` 的逻辑迁移过去，废弃 store
- **收益**：消除状态不一致风险，减少维护成本
- **实现成本**：中（需检查所有引用 project.store 的地方）

#### 3. 补充重点页面 loading 态
- **背景**：ExpertCenterView、KnowledgeView、SystemLogView、PluginCenterView 等重点页面缺少初始加载指示
- **建议**：为每个页面的主数据加载函数添加 `loading` ref + `v-loading` 指令
- **收益**：提升用户感知性能，减少「页面卡死」错觉
- **实现成本**：低（每个页面约 5 行代码）

### P1 — 中优先级（建议 2-3 个迭代内实施）

#### 4. 新增 DetailDrawer.vue 通用组件
- **背景**：9 个页面重复实现「el-drawer + 键值对详情展示」模式
- **收益**：统一详情展示交互，减少重复代码
- **实现成本**：低

#### 5. 新增 StatCard.vue 通用组件
- **背景**：7 个页面（Dashboard、专家总览、系统监控等）重复实现「图标 + 数值 + 标签 + 趋势」统计卡片
- **收益**：统一数据看板视觉风格
- **实现成本**：低

#### 6. 补充 projectContext.js 的 error 状态
- **背景**：`loadProjects()` / `ensureProjectContext()` 的 catch 仅 `console.error`，未暴露 error 给组件
- **建议**：添加 `error` ref，catch 时设置 `error.value = e.message`
- **实现成本**：极低（3 行代码）

#### 7. 清理静默错误（console.error/warn → 用户可见提示）
- **背景**：约 22 处 API 调用失败仅输出到控制台，用户无感知
- **建议**：逐一添加 `ElMessage.error()` 或 `el-alert` 提示
- **重点文件**：Workbench.vue、GraphView.vue、部分 composable

#### 8. components/ 目录按域组织
- **背景**：约 11 个业务组件散落在 `components/` 根目录
- **建议**：按业务域移入子目录（`components/project/`、`components/graph/` 等）
- **实现成本**：中（需更新所有 import 路径）

### P2 — 低优先级（长期优化）

#### 9. 命名规范化（3 处）
- `projectContext.js` → `useProject.js`
- `alliance.js` → `alliance.api.js`
- 路由 `/botCenter` → `/bot-center`

#### 10. UI 硬编码颜色替换为 CSS 变量
- 约 5-8 处非图表场景的硬编码颜色
- 替换为 `--brand`、`--success`、`--text-1` 等设计 token

#### 11. 空态补充操作引导按钮
- 约 24 个页面的空态仅有描述文案，缺少「立即创建」「去添加」等操作按钮
- 提升空态转化率

#### 12. 全局网络断开检测
- 当前仅 2 个页面有网络状态检测
- 建议在 `app.store.js` 或全局 mixin 中添加 `navigator.onLine` 监听，统一展示网络断开提示
