# 功能归属与代码布局整理

- 建立 `docs/modules/README.md` 功能导航，明确各业务域、前端页面、路由模块和新增功能落位规则；接入仓库与文档首页。
- 新增 `tools/module_catalog.py`，从真实 Cargo 元数据生成全量 workspace 清单、运行/开发/构建依赖和可执行入口，同时收录前端路由、页面、API、状态、组合逻辑及 projects 顶层入口。`--check` 检测清单漂移，避免维护另一份手工模块数量。
- 本次扫描为 143 crates、71 个 Vue 页面、24 个 API 文件、10 个状态文件、13 个组合逻辑文件。数量只表示代码存在，不表示业务验收完成。
- 将前端单体路由定义拆分为 public、project、ai、graph、workflow、alliance、market、operators、system、fallback 十个模块。路由宿主保留统一鉴权与导航生命周期。
- Node 对拆分前后的完整路由对象进行了深度比较（包含函数源码、子路由、权限元数据、重定向和顺序）：43 条顶层路由完全一致。生成目录与源码一致检查通过，新增导航链接可解析，修改空白检查通过。
- 完整前端构建未通过环境准备：本地 Vite 入口缺失，冻结安装发现现有 pnpm 锁文件与 package.json 不一致；没有将路由等价性检查冒充页面构建验收。

本轮是代码入口和模块导航的结构整理。后端历史跨域依赖、主服务进一步拆分，以及所有功能的端到端验收仍未全部完成。projects 中无顶层入口的目录仅标为待确认，不擅自移动可能仍被脚本使用的产物。
