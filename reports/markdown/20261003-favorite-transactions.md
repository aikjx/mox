# 收藏事务、失败回执与并发验证

日期：2026-10-03。范围为专家收藏 HTTP 切换，未改预约、个人偏好或旧 best-effort 辅助函数。

新增 `favorite_repository` 将真实对象校验、当前状态读取、切换和提交纳入同一 SQLite IMMEDIATE 事务。HTTP 在阻塞工作线程执行数据库操作，同实例镜像更新串行；提交成功后更新镜像并返回实际方向。不存在及跨租户对象返回 404；存储打开、锁超时、语句和提交错误返回 503，不改变镜像，不再返回伪成功，内部错误不回显客户端。

验证不使用 mock：12 个独立 SQLite 连接同步发起切换，验证 6 次新增、6 次取消且最终无丢失更新；实际 SQLite 触发器注入插入/删除失败，验证回滚；真实持锁连接验证超时与释放后的恢复。实际 JWT、TCP、生产路由和 SQLite 触发器验证 HTTP 503、镜像不变以及租户隔离/软停用重载。领域存储测试不作为模型或真实业务执行成功证据。
