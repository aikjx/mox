# 知识资源只读共享与撤权增量

本轮完成网关 KB 用户只读共享、撤权及 ACL 版本控制，当前实现权威为 docs/modules/resource-knowledge/IMPLEMENTATION-STATUS.md，接口为 docs/api/RESOURCE-KNOWLEDGE-CONTRACT.md。未部署、提交或迁移生产数据。

## 实现与业务处理

所有者/当前租户管理员 → 检查用户 ID 与预期 ACL 版本 → 在文档状态锁内增删接收者 → 原子写当前主源 → 刷新可见索引 → 文档/版本/标签/历史/检索/图谱按当前授权读取。

共享绑定资源租户，接收者只读，不可分析、挂图、创建版本、修改/删除或转授权。所有写入读取在副作用前检查写权限。授权版本独立于内容版本；内容保存不能覆盖新的 ACL，版本回滚不恢复历史权限。撤权提交后的新请求不可见；已开始读取可能完成。重复操作在版本匹配时幂等，同一状态实例的并发更新用锁与预期版本保护，不伪称已具备跨进程 CAS。
