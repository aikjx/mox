# Melody2Score：AI 深化优化审计

日期：2026-09-13。本轮为分析、函数级复现与官方文档核对，未部署新模型、未修改业务逻辑，未产生新的整体精度成绩。

## 新增复现证据

[原始 JSON](../data/melody2score-ai-20260912/ai-detail-audit.json)。以下为直接构造音符/帧的函数级测试，不代表已对相应原始音频完成端到端测量。

| 输入 | 实际行为 | 原因与修复方向 |
|---|---|---|
| MIDI 60,61,60，各0.3秒，有独立边界 | 60,60,60 | 半音众数规则抹去合法邻音；音符层不要只靠邻居改写，保留候选，按原音声学证据裁决 |
| MIDI 60,72,60，各0.3秒，有独立边界 | 60,60,60 | 八度规则未验证谐波证据或真实起音；真实跳进与倍频错误必须区分 |
| 主模型没有输出音符，复核帧有连续音高 | reviewed，空明细、无复核索引 | 只遍历已有音符；需额外扫描未覆盖的有声区间，输出时间区间级漏音候选 |
| 5秒音符只有两个相邻支持帧 | agree，dominance=1 | 支持帧内占比不等于整个音符覆盖率；需覆盖时长、连续支持、首尾证据与缺失帧比例 |

现有后处理的“不修改正确音符”注释不成立；应删除未经验证的保证。复核的 agree 也不应在界面表达为“正确”。

补充上轮结论：长音助手函数可保留不一致的 dur，但 pipeline 最终输出会按 end-start 重算 dur；因此不能据助手函数复现断言最终 API 一定输出矛盾字段。长音被截断的问题仍存在。

## 声源分离的具体问题

文件加载默认先变为16kHz单声道，随后 Demucs 再升为44.1kHz并复制两个声道。代码确认原立体声信息在分离前已丢失；是否造成多少精度损失尚未测量。建议保存原采样率/声道用于分离，分离后再生成音高模型所需单声道16kHz。

`_demucs_separate` 为 htdemucs 设置 segment=8，官方文档说明 Hybrid Transformer 最大7.8秒，属于明确的配置兼容性问题，尚未在本机真实 Demucs 推理中复现失败。应根据锁定模型的实际限制设定并用长于一个分块的音频验证。原项目已经归档，生产依赖需要锁定版本、模型哈希与维护来源。[Demucs 官方说明](https://github.com/facebookresearch/demucs)。

主模型和复核模型目前使用同一份分离/降噪后的音频。即使模型不同，也可能共同继承前处理造成的漏音。因此需要保存原音、处理音两条证据；不能把模型一致当作独立正确概率。

## AI 应如何参与

1. 音高：保留 pYIN 与 CREPE。候选输出需包含帧时间、音高、周期性、实际模型和处理链。torchcrepe 已默认使用 Viterbi，不能再把“加入 Viterbi”宣称为新增能力。可研究起音感知的跳进惩罚与按场景校准阈值，须独立评测。[torchcrepe 官方说明](https://github.com/maxrmorrison/torchcrepe)。
2. 切分：增加独立起音/止音候选，与持续音高联合判定重复同音、连音与滑音。对已有音符和未覆盖有声区间同时复核，保留被拒绝的候选和理由。
3. 多音器乐：可将 Basic Pitch 作为对照分支，它支持复音，官方说明一次一个乐器效果最好；不能据此视为混合成品歌曲万能转谱。尚未安装或测试本项目收益。[Basic Pitch 官方说明](https://github.com/spotify/basic-pitch)。
4. 乐理约束：用于候选排序、时值拼写和跨小节连音，不能把合法半音、八度跳进或长音硬改成“常见旋律”。
5. 通用大模型：建议用于解释冲突、理解用户纠正和提出可回放的修改建议。最终 MIDI 与时间必须回到音频证据核验，不应仅凭曲名、歌词或旋律常识补音。
6. 局部精算：初步识别后，对低覆盖、模型冲突、疑似漏音区域加上下文重新计算；按时间对齐并处理窗口边界。只有校准后才启用自动局部升级，避免漏掉两模型共同犯错的位置。

## 验收设计

先建立最小反例集：半音邻音、真实八度跳进、重复同音、滑音、弱起音、8秒长音、静音中稀疏伪音高、完全漏音。验收要求为保留正确音符和时间，证据不足可明确标记，但不得无声改写或给出充分支持状态。

再在冻结真实录音集分别对照：关闭/开启旧后处理；原音/分离音；pYIN/CREPE/候选融合；全片/局部升级。记录严格音符F1、止音误差、漏音/错音/八度错误、错误修改数，以及复核检出率与误报率。模型共识分数需用人工标签校准。

最终以真实录音指标决定默认策略；本轮不能给出预期提升百分点或100%承诺。先前144样例合成成绩不能替代这些新反例和真实录音验收。
