# 逐模块真实验证与修复记录

2026-10-03。本批按真实依赖顺序检查可信身份、专家注册/收藏、专家会话和站内消息，不把局部回归提升为整模块完成。功能范围仍以 [模块登记](../../docs/modules/enterprise-capabilities/README.md) 为准；完整模块逐项验证状态见 [机器台账](../data/20261003-session-isolation/module-matrix.json)。所有报告保留在 reports，代码事实与契约回归各自记录。

## 本批发现并修复

| 模块 / 缺陷 | 复现证据 | 修复与正反验证 |
|---|---|---|
| 专家会话对象授权 | tenant_red：真实 A 租户 GET B 会话返回 200，包含 B 的消息正文 | 顶层持久 tenant_id；详情、更新、追加、归档、删除、相似检索和导出统一校验；外租户 404，无业务修改 |
| 会话列表、统计与搜索 | 多个 handler 提取 TenantId 后未使用；全局集合直接统计和搜索 | 筛选在租户集合内进行，分页 total、扫描计数和概览活跃会话数只计本租户 |
| 会话事务失败回执 | storage_red：真实 SQLite 触发器拒绝提交，创建仍返回 200 | checked 持久化传播失败；创建、修改、追加、归档、删除返回 503，保留单条原值并在共享锁释放前回滚镜像 |
| 即时咨询未独立持久化 | ingress_red：存储故障时仍返回 connected；旧实现仅插入共享内存 | 单独创建即提交会话，成功前检查结果；失败不增加连接会话或后续专家计数，重载验证不依赖后来其他操作顺带保存 |
| 协作复用会话 | 原单专家咨询允许传入任意 session_id，并在提供方返回后追加消息 | 调用真实提供方前拒绝已存在的外租户 ID；取得写锁后复核；全部协作创建入口写入可信租户并走 checked 提交 |
| 前后端会话契约 | 新增所属租户会改变模型字段面，旧归一化未读取 | normSession / 列表投影统一 tenantId，14 字段面双向检查，准确源码锚点同步；不放宽字段覆盖与接线门禁 |
| 共享分页越界 | pagination_red：真实请求最大 usize 页码触发乘法溢出 panic，连接提前结束 | 共享分页偏移使用饱和乘法；真实 HTTP 返回空页和正确租户总数，不环绕到错误页面 |

设计与流程的单一主源为 [会话隔离与提交契约](../../docs/expert-alliance/23-session-isolation-and-commit.md)，含 EA-SES-01–07 及模块关系/处理流程图。无租户标记的历史 JSON 固定归 default，不猜测归属。metadata 或 body 中的 tenant_id 不能改变所有权。

## 实际运行范围

命令、退出码和完整日志在 [证据目录](../data/20261003-session-isolation/summary.json)。失败的 red、修复后的 green 以及最终回归分别保留。

最终结果：34 项 Rust 用例通过（6 组真实集成共 25 项 + 会话 handler 9 项），实际前端/HTTP 收藏恢复联调通过，前端契约 156 通过 / 1 失败；37 项会话契约均通过。生产构建、常规 Clippy、模块/导入/脚本路径/文档/流程图/格式检查通过。最终 14 条命令中 13 条退出 0、1 条覆盖率门禁退出 1。常规 Clippy 仍有 69 条网关 lint 告警，严格 lint 未清零；新测试的跨 await 锁告警已改为词法作用域消除，未增加 suppression。

- 可信租户：真实 JWT/TCP，伪造租户头拒绝、缺身份拒绝和未经认证扩展的路由拒绝。
- 专家注册/收藏：真实双租户注册、对象访问、幂等事务、重开数据库、原键恢复；实际 Pinia/Axios/Rust 故障代理联调。
- 专家会话：11 个 CRUD/查询出口、外租户访问、旧数据、故障回滚、协作外租户 session_id、即时咨询独立落盘、重载后的真实 HTTP；9 个真实 handler 回归使用专用隔离数据库。
- 站内消息：6 个真实文件事务用例，身份/幂等/独立回执与重载；不验证外部 SMTP 最终交付。
- SQLite 底座：8 个迁移、投影、往返与完整性用例。并发完整性测试仍打印一次 database locked 写失败，不能因此称每次并发写入都成功。
- 前端：37 项会话字段契约、接口与词汇门禁、实际生产构建、模块边界、框架/接口绑定、文档关联和真实 Mermaid 解析。

Rust fixture 和端口均独立，不修改运行中的业务数据库。未新增业务 mock、未使用假 LLM 或假业务成功回执。Rust 的实际共享状态测试使用真实函数和临时数据，并非替换业务服务。

## 未闭合项与后续顺序

85% 实际接口接线门禁保持原阈值；本批依然有 webhook 运维界面未挂载造成的覆盖率缺口，不能宣称全部契约通过。历史广场 store 测试仍使用服务替身与会话级收藏旧断言，待迁移到真实 fixture；全量 Vitest 未作为本批验收证据。严格 lint 债务、本批之外模块、外部提供方和完整浏览器页面流程仍未完成。

会话尚需处理全量同步写入的成本、阻塞 IO、跨进程旧快照覆盖、个人权限、用户/发送人字段语义、命令幂等、搜索资源限额与容量/SLO；会话提交、专家计数和审计 outbox 未组成一个事务。真实 LLM 成功路径无凭据时保持未验收，不调用模板答案补成功。

后续顺序：迁移旧页面测试与实际 webhook 运维接线 → 会话资源限额和存储调用治理 → 调度状态与执行取消/重试 → 知识库/OSS/图谱权限、源版本、索引一致性及故障恢复 → 其余模块按机器台账逐项推进。每项必须具备需求、真实实现、正反授权、失败路径、恢复和页面证据；本次没有宣称全平台完成。
