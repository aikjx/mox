# 资源知识核心模块实施与验收交付

日期：2026-10-01。范围：系统授权、云盘文件、知识库、知识加工、图谱、检索及对象存储的首批核心实现。**本轮并未完成全部企业功能模块或生产上线。**逐项状态及后续退出条件以[实施台账](docs/modules/resource-knowledge/IMPLEMENTATION-STATUS.md#status)为权威。

## 已落地结果

1. 文件 API 全面接入可信身份；持久化租户/所有者元数据；上传、真实下载、统计、软删除、恢复形成可重启闭环。不再注入生产样例，不再返回缺失文件的伪内容，不再把滚动哈希称为 MD5；使用 SHA-256 校验。
2. 独立知识服务从固定空列表/空版本转为真实 SQLite/FTS5 查询和不可覆盖快照；列表、更新、版本冲突、重启历史、软删除及 HTTP 错误通过集成验收。短中文词不再因 trigram 少于三字符而漏检，标签和分页限制生效。
3. 网关知识内容编辑推进版本并保存旧快照，失效旧摘要/实体/关系/投影；重新分析、建版本和回滚撤销旧投影。存储错误与批处理失败如实传播。
4. 图谱采用稳定索引，修复删除节点/边造成其他标识失效的问题，统一锁顺序。文档子图先完整验证再原子替换；无效关系不覆盖旧图；不同文档的前缀相似标识互不删除。节点与边携带来源文档和版本；文档主源可重建已挂图投影，反挂图状态跨重启保持。
5. 对象存储提供统一逻辑 key 列表契约，知识索引与 FS/S3 物理文件布局解耦。S3 分页跟随 token，解析 XML 实体并拒绝非法 XML/root/token；签名包括端口、一次路径/查询编码和排序头；空 Range/溢出边界显式处理。OSS 寻址严格使用 virtual-hosted。
6. 知识存储和 cloud-admin SDK 共用配置解析，拒绝缺配置/凭据别名冲突/错误寻址方式，取消静默换盘。网关旧存储管理不再将健康探测伪报为写路径切换成功。

## 交付边界与剩余工作

- 全域知识/图谱/检索资源授权尚未贯穿，独立 KB 仍缺可信资源身份；不能作为多租户生产就绪交付。author 仅是文档署名。
- 文件与知识源版本绑定、完整目录/共享/文件版本/配额/清理，以及两套知识主源迁移尚待完成。
- 加工仍以同步本地分析为主，持久化队列/租约/预算/幂等/取消/补偿、OCR 与真实模型评测尚待完成。
- 图谱事实审核、真实向量混合检索、低代码配置发布/灰度/回滚、持久化审计尚待完成。
- OSS 真实云端往返、STS/权限/生命周期、存储切换及旧对象定位、生产容量/SLO/灾备演练尚未执行。
- 文件 SQLite 操作仍同步，上传/下载为有界基础路径；图谱投影替换与知识索引重建仍有全量扫描成本。未宣称最优吞吐、分布式一致性、跨进程事务或完整异步生产闭环。

工作保留在共享工作区，原有用户修改保留；未做整体提交、推送或部署。已清除本轮测试对既有运行样例的纯时间戳扰动。
