# Melody2Score 本轮优化交付

日期：2026-09-13。此次完成明确缺陷修复、AI 复核增强和评测；不代表全部生产就绪问题已经解决。

## 已修改

- 默认后处理不再依据邻居多数强改半音或八度，保留 C–C♯–C、C–高八度C–C；旧启发式函数不再由默认生产后处理调用。
- 保留超过六秒的长音，统一后处理时长字段；最终谱面跨小节能力需独立验收。
- AI 复核按帧覆盖时长计算证据：支持覆盖不足70%标为证据不足；保留70%主导音高阈值。这些是保守操作阈值，尚未在真实录音上校准为正确概率。
- 扫描主模型音符之外的连续有声帧，至少三帧且达到80ms形成疑似漏音区间。空音符结果也能被复核；不会自动新增猜测音符。区间加入质量告警，桌面/独立 Web/企业页面可显示；音符支持覆盖率在桌面与独立 Web 提示中显示。
- 企业 API 上传、样例、录音入口支持 ai_review，企业 Vue 页面接通开关及质量告警，周期性评分不再标为置信度。
- 1.5拍由 hd 修正为 qd；使用 VexFlow 5 验证 tick 为四分音符的1.5倍。此检查不是完整谱面视觉验收。
- htdemucs 分块8秒改为7秒，以满足官方最大7.8秒限制。未在本机安装运行真实 Demucs 分离，不能宣称分离精度已提升。
