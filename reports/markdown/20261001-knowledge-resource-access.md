# R2 知识资源授权增量

本轮把网关 KB 文档与其图谱投影接入可信租户/所有者权限，保留内部迁移读取能力，历史无归属数据在用户路由失败关闭。没有部署、提交或迁移生产数据。

## 边界与实现

- 身份源：网关认证中间件写入的 UserInfo；拒绝缺失、停用、空租户/用户身份。客户端不能用 header/body 认领资源。
- 持久主源：KbDocument.access 的租户/所有者；角色从每次请求身份推导，只读角色拒绝写动作，管理员不跨租户。
- 授权出口：文档 CRUD、版本、实体、分析与批处理、列表、标签、分类、历史、容量、文档检索与 KB 图谱检索/统计。
- 授权先于排名：按 source_doc_id 构建可见节点/边，再搜索和计数；挂图节点由来源精确匹配，消除前缀碰撞。
- 重启：主源恢复完整共享投影，视图再筛选；归属信息持久化，历史无归属对象默认不可见。
- 对话沉淀：新知识文档归当前可信用户；源会话与云盘文件授权仍是独立待办。

## 验证

新增 HTTP 资源边界测试覆盖跨租户管理员、同租户其他所有者、伪造归属、文档/版本/实体/历史越权、修改/删除/挂图越权、标签和搜索泄漏、图谱统计及重启。服务测试覆盖只读写入、非法归属替换；网关测试覆盖匿名/伪造 header、停用身份、只读分析/创建拦截与只读搜索。

本轮 28 项测试通过、0 失败、1 项既有测试忽略；Clippy 和文档链接检查退出码为 0，Clippy 仍有存量告警。文档盘点自检及一致性检查通过。

命令退出码及完整日志见 `reports/data/20261001-knowledge-resource-access/summary.json`。既有专家门禁测试会写本地 fixture，直接恢复遇到 Windows Errno 22，已确认内容仅测试时间戳变化，并通过原子替换恢复本轮开始前的暂存基线，逐字节核对一致；详情记入 summary.json。无全 workspace、真实 OSS 或浏览器验收声明。
