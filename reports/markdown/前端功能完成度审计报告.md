#### 修复 2：ExpertWorkspaceView.vue createDoc → 真实 API 接入

**文件**：`frontend-ui/src/views/workspace/ExpertWorkspaceView.vue`
**修改范围**：import 第 273 行、第 281-282 行、函数第 789-805 行

**修改前**：
```javascript
function createDoc() { ElMessage.info('新建文档功能开发中…') }
```

**修改后**：
```javascript
async function createDoc() {
  try {
    const { value: title } = await ElMessageBox.prompt('请输入文档标题', '新建文档', {
      confirmButtonText: '创建',
      cancelButtonText: '取消',
      inputPlaceholder: '如：需求分析文档',
      inputValidator: (v) => !!v?.trim() || '文档标题不能为空'
    })
    const payload = { title: title.trim(), project_id: currentProject.value }
    const created = await kbCreateDocument(payload)
    ElMessage.success(`文档「${title.trim()}」创建成功`)
    await loadDocuments()
    if (created?.id) openDoc(created)
  } catch (e) {
    if (e !== 'cancel') ElMessage.error(e?.message || '创建文档失败')
  }
}
```

**新增 import**：
- `ElMessageBox` from 'element-plus'
- `kbCreateDocument` from '@/api/kb.api.js'

**原理**：`kbCreateDocument` API 已存在于 `kb.api.js`（POST /kb/documents），此前未被使用。修复后用户可通过弹窗输入标题，调用真实 API 创建文档，创建成功后自动刷新列表并选中新文档。取消操作不报错。

#### 修复 3 & 4：Dashboard.vue 移除 fallback 假数据

**文件**：`frontend-ui/src/views/project/Dashboard.vue`
**修改范围**：第 349-356 行

**修改前**：
```javascript
stats.value[0].value = (st && st.operators_count) ?? 8        // 虚假默认值 8
const sr = (st && st.success_rate) ?? 98.5                       // 虚假默认值 98.5
stats.value[3].value = sr.toFixed ? sr.toFixed(1) : sr
stats.value[3].up = sr >= 98
stats.value[3].trend = sr >= 98 ? '+' + (sr - 98).toFixed(1) + '%' : (sr - 98).toFixed(1) + '%'
```

**修改后**：
```javascript
stats.value[0].value = (st && st.operators_count) ?? 0          // 无数据时显示 0
const sr = (st && st.success_rate) ?? 0                           // 无数据时为 0
stats.value[3].value = sr ? sr.toFixed ? sr.toFixed(1) : sr : '—'  // 无数据显示 "—"
stats.value[3].up = sr >= 98
stats.value[3].trend = sr ? (sr >= 98 ? '+' + (sr - 98).toFixed(1) + '%' : (sr - 98).toFixed(1) + '%') : '—'  // 无数据显示 "—"
```

**原理**：API 调用失败时不应展示虚假的业务数据（算子数 8、成功率 98.5%）。改为无数据时显示 0 或"—"，趋势也显示"—"，避免误导用户。
