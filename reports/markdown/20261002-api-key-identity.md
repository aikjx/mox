# API Key 身份与生命周期归一化验证

2026-10-02。范围为 IAM core、网关凭证管理/鉴权及 AdminAccess。设计权威见 [凭证契约](../../docs/modules/iam/API-KEYS.md)。

已修复默认用户/租户绑定、仅内存鉴权重启丢失、凭证撤销不限定租户、JWT admin 字符串授权和虚构 read/write 权限。新凭证创建与撤销共用真实管理员检查及事务审计，密钥只存哈希；运行时实时读取有效期、账号、租户与撤销状态。机器路由限制为实际消息/通知流程，动态 scopes 尚未实现，前端移除假权限勾选并使用真实创建回执。

新增真实 HTTP 测试验证缺少身份、普通用户、未知权限字段、实际创建者、哈希不可作明文、列表不泄露、跨租户撤销/校验、重建鉴权、真实机器投递、伪造租户、管理路由拒绝、审计失败完整回滚、独立连接撤销、重复凭证拒绝、旧明文升级、有效期非法/过期、旧 scopes、停用账号/租户和撤销管理员标志。SQLite 文件、签名 JWT、TCP 服务均为真实实现，无假业务服务。

共 33 项 Rust 测试通过：真实业务/HTTP/持久化 18 项，认证及路由策略 13 项，IAM core 2 项；接口注册生成测试 1 项通过。前端生产构建、Gateway/IAM 全 targets Clippy、文档链接、端口、前端模块化、时间格式、限定文件格式与 diff 校验通过，详见 [检查记录](../data/20261002-api-key-identity/summary.json)。旧 Clippy/构建警告、215 条文档路径提示和 284 条端口警告仍保留，不宣称全库零警告。前端构建不等于完整浏览器验收；历史前端隔离测试只补真实 Pinia 初始化，不作为本批真实业务成功证据。

验证中另修复联盟事件日志查询的 Rust 生命周期编译错误：在语句所有者释放前收集结果，并迭代结果集合，保留原错误行处理语义。没有改动其业务查询或外部任务的其余修改。

本批没有宣称全系统开发完成。仍需历史明文迁移/轮换、动态权限执行、凭证和审计分页、速率/容量及 SLO、浏览器业务验收、跨主机集群；SMTP/LLM/OSS 正向外部链路仍须真实环境验证。撤销不取消已认证的处理中请求；状态/校验/审计查询未具备生命周期写命令的共同事务保证。
