# IAM 权限管理归一验证

2026-10-02。契约主源：[IAM 业务权限管理](../../docs/modules/iam/README.md)。本批未使用 mock 业务服务。

开发了实际权限点登记、角色直接授权读取与版本化替换、授权和审计原子提交。新接口由生产融合与独立 IAM 路由装配；角色页面已接入真实接口。统一有效权限策略供 IAM 查询与消息发送复用，删除不能跨实例失效的内存权限缓存。

旧用户与角色入口补充真实超级管理员及对象租户校验，保护用户角色绑定、角色修改/复制、状态与密码重置。角色绑定仓储先校验全部目标再事务替换，非法目标不会清空原关联。

真实 TCP 测试覆盖密码哈希登录并使用实际签发 JWT、普通用户提权拒绝、跨租户查询/修改拒绝、授权后实际消息投递、撤权后发送拒绝、已撤销管理员旧 JWT 拒绝、两个独立 IAM 连接并发保存同一版本只允许一个成功。通过真实 SQLite 触发器拒绝审计插入，确认授权与角色版本完整回滚；重新打开实际数据库后可读持久化授权。角色继承循环与停用角色的消息验证沿用专项回归。

测试、构建、Clippy 和门禁最终退出码位于 [summary.json](../data/20261002-iam-permission-admin/summary.json)。日志与源文件哈希同目录。构建检查曾发现独立 IAM 装配入口未更新，以及共享的旧角色遍历函数被误移除，均已修复后重新验证；没有通过删除检查或降低阈值规避错误。静态路由数组更新到 246，与生成注册表校验一致。

最终 17 项网关专项测试、2 项 IAM 核心测试及 1 项注册表生成测试通过。前端生产构建、Gateway/IAM Clippy all-targets、文档链接、端口、前端模块化、时间格式出口、范围内格式与差异检查均通过。Clippy 和构建仍有既有告警，文档保留 215 条历史路径告警；没有关闭规则。前端新增组件曾触发深路径导入门禁，现已通过统一 barrel 出口解决。

尚未完成：浏览器完整权限编辑/发送链路、其他管理模块统一授权、旧管理写事务与管理员撤权共同提交排序、旧业务全面审计、菜单/数据权限策略归一、权限目录规模分页、跨主机集群、配额和负载 SLO。该报告不代表整个企业系统已完成。
