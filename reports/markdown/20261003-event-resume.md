# SSE 持久续传与融合验证（2026-10-03）

现有业务事件 SSE 支持显式 Last-Event-ID，在认证租户内读取 SQLite 历史，然后接入实时广播；不新增第二套事件 API。历史上限 200 条、总载荷 2 MiB、单条 1 MiB。未知/外租户游标统一 410，超限 409，非法游标 400，存储或载荷错误 503。先订阅后读取事务快照，有限 ID 集合去除历史与实时重叠。

前端 `start({ lastEventId })` 实际发送游标，HTTP 错误携带 status 供调用方决策；引擎不自动重连或保存游标。认证变化仍取消旧连接。生产 CORS 原明确源列表保持，仅加入续传头；提取同一 CORS 构造函数给生产入口与真实 OPTIONS 测试复用。

## 真实验证

- 初始 Rust 红测：未知游标仍返回 200，修复后返回 410；已存本租户事件补发，其他租户不出现，旧 ID 重复广播被去除，新专家注册经真实 HTTP 接上实时帧。
- 临时 SQLite 真实写入：200 条成功、201 条超限；单条与总字节超限拒绝；损坏载荷、实际数据库打开失败返回 503，未退化为空历史。
- 前端传输引擎实际连接 Rust/JWT/SQLite，接到历史事件；410 回调与非法游标拒绝验证通过。首轮探针路径未解析导致失败，改为绝对路径后复现未传游标造成收不到历史帧，两个失败日志均保留。
- 生产 CORS 层真实 HTTP OPTIONS 红测显示缺续传头；修复后明确 origin、credentials 与 Last-Event-ID 通过，未配置源不获允许源响应头。
- 本轮没有新增 mock 服务、业务成功桩或跳过测试。存量前端契约/生命周期测试包含既有测试替身，真实前端至 Rust 证据单独记录，不能混称全套测试均无替身。

完整命令、退出状态、计数及源码 SHA-256 见 [summary.json](../data/20261003-event-resume/summary.json)。最终门禁警告原样保留，不把退出 0 解释为零告警。前端构建通过，未做浏览器 DOM 验收。

最终通过 191 项网关库测试和 18 项指定集成测试，共 209 项 Rust 测试；160 项前端契约/生命周期测试、4 项 Node 传输测试、41 张 Mermaid 语法校验。真实前端至 Rust 探针计入该集成测试，不重复增加测试数量。17 项最终检查全部退出 0，Clippy 仍有 69 条存量库警告；文档历史路径、端口及前端注释提示见汇总。格式检查仅针对本轮 replay、stream 与集成测试文件，不宣称全仓格式通过。
