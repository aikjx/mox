### 2. JWT Secret 环境变量化

**修改文件**：`config.rs`（新增 `resolve_jwt_secret()` 方法）+ `lib.rs`（`GatewayState::from_config` 启动时调用）

| 项目 | 修复前 | 修复后 |
|---|---|---|
| Secret 来源 | 硬编码 `"change-me-in-production"` | 环境变量 `JWT_SECRET` |
| 未设置时（debug） | 静默使用硬编码值 | 使用 dev 密钥 `"dev-only-insecure-secret"` + 打印警告 + 自动开启 dev_mode |
| 未设置时（release） | 静默使用硬编码值 | **panic!** 拒绝启动，提示设置 `JWT_SECRET` |
| 额外开关 | 无 | `MOX_DEV_MODE=1` 可在 release 中临时开启 dev 模式（打印警告） |

**读取逻辑**（`AuthConfig::resolve_jwt_secret()`）：
```
1. 优先读取 JWT_SECRET 环境变量 → 非空则使用
2. 未设置且 debug_assertions → 使用 dev 密钥 + eprintln 警告 + dev_mode=true
3. 未设置且 release → panic!("JWT_SECRET 环境变量未设置！生产环境禁止使用默认密钥启动。")
4. MOX_DEV_MODE=1 → 强制 dev_mode=true（仅限临时调试）
```

### 3. Dev 令牌保留方式（配置开关）

**修改文件**：`auth.rs`（`auth_middleware` 函数）+ `config.rs`（新增 `dev_mode` 字段）

- 新增 `AuthConfig.dev_mode: bool` 字段，默认值由 `cfg!(debug_assertions)` 决定（debug=true, release=false）
- `dev_mode=true` 时：任何非空 Bearer token 均可通过认证（解析失败时构造 `dev-user` / admin 角色的 UserInfo 放行）
- `dev_mode=false` 时：须通过 `validate_token()` 的 JWT 结构 + 声明校验
- 前端 dev 令牌在开发环境（debug build）自动可用，无需额外配置
- 生产环境（release build）默认关闭 dev_mode，须设置 `MOX_DEV_MODE=1` 临时开启（会打印警告）

### 4. CORS 配置收紧

### 5. 附带修复：monitor.rs 编译阻塞

**修改文件**：`monitor.rs`（预存 bug，非本次引入）

- 修复：将两处局部变量重命名为 `ok_count`（`metrics_detail` 函数 + `quality` 函数）
- 影响：此为预存编译阻塞，修复后 cargo build 方可通过

## 第四部分：遗留问题

1. **JWT 签名验证未实现**：当前 `auth.rs::validate_token()` 仅做 JWT 结构检查（3 段 + base64 解码 payload），未验证 HMAC/RS256 签名。生产环境建议引入 `jsonwebtoken` crate 实现完整签名校验。本次 P0 修复聚焦于白名单收紧 + secret 环境变量化 + CORS 收紧，签名校验列为 P1 后续迭代。

2. **非 admin 视图 console.warn（46 处）**：project/expert/ai/workflow 等业务视图中仍有 46 处 console.warn/console.error，部分为数据加载失败且无 ElMessage 反馈。本次审计重点为 admin 面板（22 处），非 admin 视图的静默错误清理建议在下一轮迭代中逐域处理。

3. **CORS 生产域名配置**：当前默认 origin 列表仅包含 localhost 开发地址。生产部署时须通过 `CORS_ALLOWED_ORIGINS` 环境变量设置实际生产域名（逗号分隔），例如 `CORS_ALLOWED_ORIGINS=https://app.example.com,https://admin.example.com`。

4. **JWT_SECRET 生产部署**：release 构建启动时必须设置 `JWT_SECRET` 环境变量，否则将 panic 拒绝启动。建议使用强随机密钥（≥32 字节），并通过密钥管理服务注入。

5. **dev_mode 生产风险**：`MOX_DEV_MODE=1` 可在 release 中绕过 JWT 严格校验，仅限临时调试使用。生产环境应确保该环境变量未设置，且 `JWT_SECRET` 已正确配置。
