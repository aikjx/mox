# IAM 安全审计分页与只读入口验证

2026-10-02。架构和接口权威见 [IAM 安全审计](../../docs/modules/iam/AUDIT.md)。

新增核心审计查询，管理员校验、租户约束、精确过滤、COUNT 与 LIMIT/OFFSET 同一读事务；返回真实分页对象，旧数组调用者须迁移。时间按实际瞬间过滤/排序，增加幂等表达式索引。存储失败实际 503，未知状态保持 null，不返回审计快照或哈希字段。

新增只读低代码 audit.page、独立导航和管理审计页入口，不合并原操作日志或登录日志来源。只读契约不要求假写接口，校验器及引擎阻止内置写入口。修复缓存只看少数字段而可能保留旧状态的问题，服务端新行引用驱动刷新；修正错误的低代码凭证端点台账。

新增真实 SQLite/JWT/TCP 测试：130 条七页读取、跨租户排除、未记录状态、精确 action/actor/time 联合过滤、等价时区包含边界、真实瞬间排序、SQL 注入字符串、非法参数、超大页号、索引计划、实际断表 503 和旧 JWT 撤权拒绝。新增 Node 契约测试使用实际校验函数，无业务服务替身；历史前端隔离测试不计入真实验收。

集成检查发现新增联盟事件出口仍把已解构的租户字符串当成 tuple，并缺少 IntoResponse 导入。保留原逻辑，修正四处字符串用法及导入；首次失败与复查日志均保留在证据目录，不以删除失败记录替代修复。

复查发现 DataTable 默认 10 条与查询引擎 20 条不一致；添加 initialPageSize 并由引擎传入当前页大小。新增 2 项实际 Vue/Element Plus 组件交互测试，在 happy-dom 中验证 20/50 条初始化及下一页查询边界，无组件或业务服务替身；修复前两项均失败，修复后通过。此证据不计为浏览器端到端验收。

最终验证：24 项 Rust 测试（网关 22 + IAM core 2）、7 项 Node 契约测试、2 项真实组件交互测试、1 项注册表测试通过；前端生产构建、Clippy、模块化/locale/文档链接/端口门禁及范围内格式与 diff 检查通过。Clippy 仍有已有建议，端口保留 284 项 WARN、文档链接保留 216 项提示、前端门禁保留 26 项注释提示；退出码通过不等于这些提示已消除。
