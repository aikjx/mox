## 设计哲学三定律

1. **元数据驱动一切**：所有业务实体/字段/关系/流程/权限/菜单/页面/报表都通过元数据定义，新增业务模块 = 配置元数据，零代码。
2. **架构只处理流程**：架构层只提供5个通用引擎（实体/流程/权限/页面/融合），业务逻辑 = 元数据配置 + 规则脚本。
3. **行业融合零摩擦**：每个行业 = 一个Industry Pack（实体/流程/权限/菜单/页面/报表/数据映射模板），导入 = 秒级生成完整行业系统。

## 多租户三档隔离

| 级别 | 实现 | 适用 |
|------|------|------|
| L1 逻辑隔离 | 所有表加 tenant_id，查询自动过滤 | 中小企业/SaaS标准版 |
| L2 Schema隔离 | 每租户独立Database Schema | 中大型企业/SaaS专业版 |
| L3 集群隔离 | 每租户独立数据库集群 | 金融/政府/大型企业 |

---

## 四维权限体系

1. **功能权限（RBAC）**：用户→角色→权限（菜单/按钮/API）
2. **数据权限（Data Scope）**：全部/本部门/本部门及子部门/仅本人/自定义规则
3. **部门权限（Org Chart）**：无限层级部门树，用户可属多部门
4. **菜单权限（Menu Tree）**：菜单树自动生成，无权限自动隐藏

## 专家联盟（7服务+1Sidecar）

```
gateway-http + gateway-grpc (协议分流)
    ↓
alliance-scheduler (专家匹配+任务编排+DAG)
    ↓
alliance-executor (ReAct循环+工具调用)  ←→  expert-memory (RAG记忆)
    ↓                                    ←→  expert-registry (专家注册/评分)
alliance-fusion (多专家结果融合+投票)    ←→  expert-agent (无状态Agent运行时)
    ↓
ai-inference Sidecar (Python推理+vLLM)
```
