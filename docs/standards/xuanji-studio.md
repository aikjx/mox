# 璇玑工作台（Xuanji Studio）

> 用户视角融合层 · 豆包式低门槛交互 · 打开即用

## 定位

工作台是整个璇玑系统的**用户直通入口**：把图谱治理、项目看板、API 能力、代码执行
全部收敛到一个零门槛页面。设计理念借鉴豆包（字节跳动）的产品方法论，全部自研实现：

| 设计理念 | 豆包做法 | 工作台落地 |
|---|---|---|
| 零门槛直通 | 访客模式，先试试看 | 打开 `/studio` 即用，无注册无配置 |
| 超短链路 | 场景化入口，声落即出 | 首页场景卡片点击直达，意图预判 |
| 在线运行 | MarsCode 代码执行 | JS 代码 vm 沙箱真实执行（3s 守卫） |
| 上下文感知 | #File 引用 | 图谱上下文 AI 咨询（/atlas/consult） |
| 偏好记忆 | 用户习惯学习 | localStorage 记住最后页/示例/端点 |

## 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/studio` | 工作台页面（单文件原生 JS，零依赖） |
| POST | `/studio/run-code` | JS 代码在线运行（vm 隔离沙箱） |
| POST | `/studio/run-code/precheck` | 语法预检（不执行） |

## 沙箱安全模型

- **零 IO**：无 require / process / fs / network 注入，纯计算全局白名单
- **超时守卫**：3 秒强制终止（防死循环）
- **体积守卫**：64KB 代码上限
- **日志守卫**：console 捕获上限 200 条
- **序列化防护**：循环引用 / BigInt / 函数安全序列化，深度限制 6 层
- **REPL 语义**：末尾表达式自动回显（async IIFE 包裹）

## 页面结构（黄金比例 1:1.618）

- 顶部：品牌 + 全局搜索（`/` 聚焦，260ms 防抖即搜图谱）
- 五页签：首页（场景卡片）/ 代码运行 / API 游乐场 / 图谱体检 / 项目看板
- 代码区：编辑器与结果面板按黄金比例分割（1 : 1.618）
- 底部状态栏：服务状态 + W 族验证 + 项目数 + 健康分（30s 心跳）
