3模块化可插拔：运行时互换，架构不写死

关键组件全部抽象为 trait 对象，运行时注入不同实现。
  • 专家匹配器：Arc<dyn ExpertMatcher>，规则匹配器 / 模块化权重匹配器运行时互换
  • 任务存储：新增 TaskRepository trait，内存 / 文件快照（JSON 原子落盘）/ 未来数据库插拔
  • 执行器桥接：ExecutorBridge trait，HTTP 远程 / 进程内 / Noop 三种实现
  • 配置子系统：ConfigEngine + MemoryConfigStore + 10 个内置领域专家 + ConfigSynchronizer 权重热同步，全部接入 server 装配
  • SDK：从全 Stub 落地为真实 HTTP 客户端（任务 / 状态 / 专家搜索 / 健康检查）

4企业级增强：健壮性与可运维性

  • 超时保护：DAG 节点执行 tokio::time::timeout，超时按失败处理（防悬挂）
  • 并发上限：提交时校验队列容量 + max_concurrent_tasks，超限返回 SchedulerFull
  • 租户贯通：scheduler/executor 路由均从 X-Tenant-Id 解析租户，替换硬编码 Uuid::nil()
  • 持久化：任务状态文件快照，进程重启可恢复；环境变量 ALLIANCE_TASK_STORE 切换
  • LLM 密钥校验：is_provider_available 改为按真实 API Key 判定，不再"未配置也视为可用"
  • 错误码：新增 SchedulerUnavailable，SDK 连接失败可识别
  • HTTP 超时：SDK 客户端默认 30s 超时
