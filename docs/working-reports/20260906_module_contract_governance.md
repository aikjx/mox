## 已落地

- 云存储管理实现迁入 `mox-cloud-admin-sdk`，云 API 保留契约；旧 `admin` feature 和 `admin::store_admin` 导入需要迁移。
- 联盟 HTTP 适配器迁入 `mox-alliance-http-sdk`，网关保留兼容导出；算法公共错误类型下沉 foundation，原平台算子导出保持类型一致。
- 流程桥接、数据目录通过流程 SDK 使用模型；删除融合模块未使用的流程服务依赖。
- `mox-platform-module-core` 统一身份、契约主版本、依赖排序、路由独占和启动状态。配置错误先于模块初始化失败；必需模块失败阻止宿主启动，可选模块失败明确降级。
- 编排宿主读取模块清单并暴露启动状态；系统模块不再自动创建管理员或输出明文令牌。新环境需显式初始化，或使用不包含该模块的部署配置。

- 统一架构门禁同时运行两套既有规则，任何 P0/P1 都产生失败退出码。
