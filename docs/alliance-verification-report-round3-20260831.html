三、本轮架构改进

  • 构建 / 监听分离：SchedulerServer 与 ExecutorServer 抽出 build_app()，与 run() 解耦。构造注入 → build_app → oneshot 直接测真实路由，无需真实端口，可复用、可测试。
  • 配置继承语义落地：模块级 provider 缺失时从全局继承（「未配置回退到全局默认」从文档变为代码事实）。
  • 错误码单一事实源：任务操作统一 TaskNotFound(2000)，SDK 的 error_code_from_u32 与服务端输出一致。
  • 枚举归一化：TaskPriority 与全部联盟枚举统一 snake_case wire format。
  • 租户隔离验证：集成测试显式验证 X-Tenant-Id 贯通；错租户查询返回 403（隔离生效）。
