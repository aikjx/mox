## 三、本次归一化修正（已验证零回归）

**问题**：`xuanji_optimize` 中 `HarnessProfile.plugins` 曾硬编码列 7 个业务专家（`algorithm/business/data/observability/permission/resource/security`），与实际运行时 `all_experts()` 装载的 **双璇玑十四维** 不一致——属于"整理优化好，归一化"要解决的描述漂移。

**修正**（`pipeline.rs:42-56`）：
```rust
let experts = crate::experts::all_experts();
let profile = HarnessProfile {
    name: "default-xuanji".into(),
    plugins: experts.iter().map(|e| e.id()).collect(),  // 由 all_experts() 实时派生
    audit_enabled: true,
    model: ModelAdapterConfig::default(),
};
```
修正后 `plugins` 与 `run_experts(crate::experts::all_experts())` 强一致，**消除漂移**，且无需维护两份专家清单。重测全绿（2026-08-18 复测 146 项），确认无回归。
