# 资源知识全维交付检查

> RK-DEL-01 · 2026-10-01 · 验收维度与证据导航。唯一模块完成状态在[实施台账](docs/modules/resource-knowledge/IMPLEMENTATION-STATUS.md#status)，本表不建立另一份完成率。

业务全链路见[实际业务流程](docs/modules/resource-knowledge/BUSINESS-FLOWS.md#implemented)；架构、数据、接口各自沿用[模块入口](docs/modules/resource-knowledge/README.md#navigation)登记的权威来源。企业完成必须逐项满足验收条件并附真实环境证据。

| 维度 | 验收问题与必要证据 | 工作包 |
|---|---|---|
| 身份与租户 | 可信身份、停用用户、两租户同 ID、不接受伪造头 | R2 |
| 资源权限 | 所有者、管理员范围、只读、共享及撤权出口一致 | R2 |
| 主源归一 | 一资源一可写主源；迁移映射、历史归属、备份可恢复 | R2 |
| 数据完整性 | 对象摘要、不可变版本、删除引用、损坏失败传播 | R3 |
| 文件产品 | 目录、移动、版本、回收、保留与配额实际闭环 | R3 |
| 知识来源 | 精确文件版本或内联源、制品与知识版本可追溯 | R3 |
| 并发一致性 | 内容与 ACL 冲突、跨进程 CAS、过期加工不覆盖 | R2/R4 |
| 工作流 | 持久化任务、租约、重试、取消、幂等、恢复和补偿 | R4 |
| 解析安全 | MIME、压缩炸弹、宏、OCR 隔离、超时与资源限额 | R4 |
| 低代码配置 | schema、依赖图、草稿/发布/回滚与任务冻结配置 | R4 |
| 模型能力 | 真实模型探测、降级、版本、预算与质量数据集 | R4/R5 |
| 图事实治理 | 文档证据、事实确认、版本过滤、删除与图一致 | R5 |
| 检索质量 | 授权先召回、关键词/向量/图、来源定位与评测 | R5 |
| 专家联盟 | 来源权限、任务闭环、结论证据与受控发布 | R4/R5 |
| 远端对象 | 实际 OSS/S3 往返、STS、轮换、提供方差异 | R6 |
| 存储迁移 | 对象位置、校验、切换、checkpoint、中断续作与对账 | R6 |
| 审计与观测 | 安全事件持久化、trace、指标、报警与诊断关联 | R7 |
| 容量与成本 | 真实并发/大文件测量、索引预算、调用成本上限 | R7 |
| 灾备与升级 | 备份恢复演练、版本兼容、灰度、回滚与数据保留 | R7 |
| 产品与交付 | 正文编辑、冲突提示、权限体验、端到端与运行证据 | R7 |

R2–R7 的退出条件见[实施台账](docs/modules/resource-knowledge/IMPLEMENTATION-STATUS.md#sequence)。当前本地或模拟测试不等于真实云端验收，接口存在不等于 UI/业务闭环，目录与静态能力清单不等于已开发完成。
