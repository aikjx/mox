跨流程强关联边 · 12 条不变式（EB-ALL-01~12）

违反任意一条 = 名实分裂 = PR 阻断
EB-ALL-01
PHASE-1 意图 → PHASE-2 组队
组队必须使用 PHASE-1 输出的安全标签进行强制专家路由
安全类意图 + team 不含安全专家 → security_note ≠ ∅
EB-ALL-02
PHASE-2 组队 → PHASE-3 辩论
辩论并行度 = team.len()，单专家 60s 超时隔离不阻断
辩论专家集合 = 组队集合（除被超时隔离排除的）
EB-ALL-03
PHASE-3 辩论 → PHASE-4 合成
合成必须包含所有 validCount 意见，不得强裁分歧
SynthesizeResult.divergences.len ≥ DebateResult.consensus.divergences.len
EB-ALL-04
PHASE-4 合成 → PHASE-5 门禁
门禁必须校验合成主题 vs 意图类别的一致性
不一致 → reasons 必须包含 intent_mismatch
EB-ALL-05
PHASE-5 门禁 → PHASE-6 学习
学习只沉淀门禁通过的处理，防止技能污染
GateResult.passed=false → Phase-6 必须跳过不执行
EB-ALL-06
XOPT-3 会诊 → XOPT-6 验证
专家 veto=true 触发璇玑验证 vetoed=true（单向不可逆）
ExpertOpinion.risk[].veto 任一=真 → verify() 返回 vetoed=true
EB-ALL-07
XOPT-4 裁决 → XOPT-6 验证
同优先级维度约束冲突无法裁决 → escalated → 升级 Blocking
ReconciledPlan.conflicts[].escalated=true → verify() vetoed=true
EB-ALL-08
XOPT-6 验证 → XOPT-7 治理
璇玑验证最高权限，治理闸门不可覆盖验证结论
algo.vetoed=true → govern() 必须 Blocked（治理绝对不可覆盖）
EB-ALL-09
XOPT-1~8 ↔ BP-6 融合
BP-6 内部必须串行执行 XOPT-1 到 XOPT-8，不可跳步
BP-6 GovernanceReport = XOPT-8 输出的深拷贝，字段完全一致
EB-ALL-10
BP-5 推进 → BP-6 融合
任务必须处于 InReview/Done 才能触发融合优化流程
Task.status ∉ {InReview, Done} → /api/xuanji/optimize 412
EB-ALL-11
CHAT-2 请求 → PHASE-0~6
SSE 帧 phase_index 必须严格 0→6 单调递增，缺帧即降级
SSE 缺帧 → 前端显示 degraded 标记 + 灰色芯片 + 告警日志
EB-ALL-12
BP-9 判重 → BP-1~3
P9 先判重后立项，在 BP-1/2/3 之前强制执行（铁律）
请求头缺 X-P9-Dedup-Token → 428 Precondition Required
