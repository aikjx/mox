发布应用

使用 CLI 工具一键发布你的应用到 MOX 应用商店：

python tools/publish_app.py \
  --app-dir ./my-app \
  --app-key my-crm \
  --name "客户关系管理" \
  --version 1.0.0 \
  --author "你的公司" \
  --category "办公协同" \
  --upload --publish

应用包格式 MXAP，包含前端、数据、配置和数字签名。发布后自动审核上架。
