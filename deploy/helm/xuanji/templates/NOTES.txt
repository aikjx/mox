XUANJI PLATFORM - 一键伞图部署 (UMBRELLA CHART)
=================================================

Release name:     {{ .Release.Name }}
Namespace:        {{ .Release.Namespace }}
Chart version:    {{ .Chart.Version }}
App version:      {{ .Chart.AppVersion }}
Gray Release:     {{ .Values.global.gray.enabled }}
Gray Stages:      [{{ join ", " .Values.global.gray.stages }}]%

========================================
一、首次一键部署（最简版）
========================================
  $ helm dependency build deploy/helm/xuanji
  $ helm install xuanji deploy/helm/xuanji \
      --namespace xuanji-system --create-namespace

  # 自定义参数（例如打开灰度 + 灾备多区域）
  $ helm install xuanji deploy/helm/xuanji \
      --namespace xuanji-system --create-namespace \
      --set global.gray.enabled=true \
      --set xuanji-dr.enabled=true \
      --set xuanji-observability.enabled=true

========================================
二、灰度 Warmup 4 阶段发布
========================================
  # 1) 启动灰度 (1%)
  $ helm upgrade xuanji deploy/helm/xuanji -n xuanji-system \
      --set global.gray.enabled=true --set canary.weight=1

  # 2) 运行随附的 Warmup 脚本做 4 阶段健康检查
  $ powershell -ExecutionPolicy Bypass -File scripts/Gray-Warmup.ps1

  # 3) 或者手动逐步推进
  $ helm upgrade xuanji deploy/helm/xuanji -n xuanji-system --set canary.weight=10
  $ helm upgrade xuanji deploy/helm/xuanji -n xuanji-system --set canary.weight=50
  $ helm upgrade xuanji deploy/helm/xuanji -n xuanji-system --set canary.weight=100

========================================
三、一键安装 + 观察所有子组件
========================================
  $ helm dependency update deploy/helm/xuanji
  $ helm template deploy/helm/xuanji --namespace xuanji-system | kubectl apply -f -
  $ kubectl get pods -n xuanji-system -w
  $ kubectl get svc -n xuanji-system

========================================
四、子 Chart 控制
========================================
  # 仅打开 DR（关闭 observability 可省资源）
  $ helm install xuanji deploy/helm/xuanji -n xuanji-system \
      --set xuanji-observability.enabled=false

  # 禁用 DR，单集群部署
  $ helm install xuanji deploy/helm/xuanji -n xuanji-system \
      --set xuanji-dr.enabled=false

========================================
五、卸载
========================================
  $ helm uninstall xuanji -n xuanji-system
  $ kubectl delete namespace xuanji-system

========================================
六、验证部署完整性
========================================
  $ helm list -n xuanji-system
  $ helm status xuanji -n xuanji-system
  $ kubectl get deploy,sts,svc,hpa,pdb,configmap -n xuanji-system

提示：任何阶段健康检查不通过，运行 scripts/Gray-Warmup.ps1 -ForceFailPercent 80
模拟回滚日志写入 rollback.log 并退出 1。
