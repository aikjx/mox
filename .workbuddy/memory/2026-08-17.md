## 沙箱 cargo 运行铁律（本次复现）
- 前台 Bash 写 `target/` 被沙箱拦截（os error 5），cargo 必须 `run_in_background=true`。
- `target/debug` 锁文件（`.cargo-lock`/`.cargo-build-lock`）会因被杀的后台 cargo 任务遗留"拒绝访问"状态，导致后续 cargo 打开即 os error 5；净化手段：① 清空该 target 目录锁文件（沙箱旁路 rm）或 ② 改用全新 `CARGO_TARGET_DIR` 目录（当前有效）。`-j 1` 可避免并行 rustc 对 .o 的锁竞争。
