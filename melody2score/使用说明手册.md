# Melody2Score 使用手册

> 把一段音频或一句哼唱，变成一张看得懂的简谱。

这份手册用大白话教你：装好、打开、用它把歌转成谱。不需要懂任何编程或技术知识。

## 一、这个工具是干什么的？

一句话：**你唱一段旋律，或者给它一段音乐，它帮你把音符写成简谱。**

具体能做三件事：

1. **录音转谱**：对着麦克风唱一句（比如哼一段小星星），它把每个音写成数字简谱。
2. **音频转谱**：给它一个 mp3 / wav 音频文件，它把里面的旋律提取成简谱。
3. **猜歌名**：唱几句后，它会告诉你「你唱的可能是哪首歌」并给出匹配度。

输出的简谱长这样：

```
简谱： 3 3 4 5 5 4 3 2 1 1 2 3 3 - 2 2 -
调式：C 大调    速度：96 BPM    共 16 个音符
```

数字 1–7 就是 do re mi fa so la si；`.` 是高一八度、`_` 是低一八度、`-` 表示这个音拖长一点。

## 二、怎么把它装到电脑上

你需要一台 **Windows 电脑**（Linux / macOS 也能用，但下面按 Windows 讲）。

### 前提：电脑上有 Python

1. 打开浏览器，去 [python.org](https://www.python.org/downloads/) 下载最新版 Python。
2. 安装时**一定勾选**「Add Python to PATH」（把 Python 加到系统路径）。
3. 装完按 `Win + R`，输入 `cmd` 回车，敲 `python --version`，如果显示版本号说明成功。

### 安装本工具需要的"零件"

1. 打开命令行（`Win + R` → `cmd` 回车）。
2. 输入下面这行命令，回车，等它自动下载安装（约几分钟）：
   ```
   cd /d d:\a10\aikjx\gitcode\infotopograph\melody2score
   python -m pip install -r requirements.txt
   ```
3. 看到一大串「Successfully installed」说明装好了。

> 如果中间报错提示 numpy 版本冲突，先单独运行：
> ```
> python -m pip install "numpy>=1.23,<2.0"
> ```
> 再重跑上一步。

## 三、怎么打开它

安装好之后，**每次打开都做这两步**：

1. 打开命令行（`Win + R` → `cmd` 回车）。
2. 输入下面任意一行，回车，界面就出来了：

| 想用哪种 | 输入这行命令 |
|---------|------------|
| **图形窗口（推荐，最好用）** | `cd /d d:\a10\aikjx\gitcode\infotopograph\melody2score` 然后 `python app/gui.py` |
| **网页版（用浏览器）** | 同上切目录后 `python app/webui.py`，然后打开 `http://127.0.0.1:8012` |

> **推荐用图形窗口**（GUI）：按钮大、看得清、录音还带音量条，最顺手。

## 四、怎么把你的歌变成简谱

打开图形窗口后，有 **3 种办法**，选一个你喜欢的：

### 办法 A：对着麦克风唱（最常用）

1. 点击「🎙️ 录音并识别」按钮。
2. 先选录音时长（3 秒 / 10 秒 / 30 秒 / 60 秒），一般选 **30 秒**。
3. 屏幕会倒计时「3、2、1」，然后开始录音——**这时你就开始唱/哼**。
4. 到时间自动停止，几秒钟后右边就显示出简谱和五线谱了。

> 小技巧：唱的时候**对着麦克风、音量平稳、不要离太远**，这样识别最准。

### 办法 B：给一个音频文件

1. 点击「📂 选择音频文件」。
2. 选一个 mp3 / wav 音乐文件。
3. 程序自动开始识别，稍等几秒出结果。

### 办法 C：用内置的示例歌

1. 在「内置经典样例」下拉框里选一首（比如小星星、生日快乐歌）。
2. 点「识别选中样例」。
3. 可以直接看这首歌的转谱效果，也可以点「▶ 播放原曲」先听一遍。

## 五、界面上的东西都是什么

识别完成后，右侧会显示几个标签页，每个都是一种"看结果的方式"：

| 标签页 | 说明 |
|--------|------|
| **简谱** | 数字谱，最常用，一眼能看懂唱什么音 |
| **五线谱** | 传统乐谱样子（豆芽符号），懂乐理的看这个 |
| **音高轮廓** | 一条阶梯线，展示整段旋律的起伏走向 |
| **音符明细** | 表格，列出每个音符的音名、出现时间、时长 |
| **识别歌曲** | 告诉你「你唱的可能是什么歌」及匹配度 |

顶部还有几个**数字卡片**：调式（如 C 大调）、速度 BPM、音符数。

页面底部有几个按钮：
- **▶ 试听原曲**：播放你选的音频。
- **🎹 播放钢琴曲**：把识别出的简谱用钢琴音色播放出来，听听转得对不对。
- **⏹ 停止**：停止播放。

### 左上角参数（不用动也能用）

- **音高模型**：`tiny / small / full`。默认 tiny（最快）。想要更准就选 `small`，就是慢一点。
- **识别场景**：选「人声模式」唱的歌，选「器乐/通用模式」放音乐。
- **降噪**：默认「开启」，周围环境吵时保留开启。

## 六、我唱的不是内置的歌，能识别吗

**能。**

内置的 16 首只是拿来演示和帮你熟悉操作的。你随便唱一首，哪怕曲库外、甚至自编的旋律，它都能转成简谱——转谱跟曲库无关。

「识别歌曲」那个功能，只是额外帮你猜「是不是内置的某首歌」。如果你唱的不是那 16 首，它会显示"未在曲库中命中"，**但简谱照常给你**，不受影响。

## 七、怎么把结果保存下来

1. 识别完成、确认结果满意后，在下方**标题框**里给你的旋律起个名字（不填也行）。
2. 点「💾 保存 Markdown」按钮。
3. 程序会自动生成一份图文报告（含概要、简谱、音符明细、算法说明），并告诉你存到哪了（一般在 `app/exports/` 文件夹里）。

> 保存的是标准的 Markdown 文档，可以用记事本、Typora、VS Code 打开或分享给别人。

## 八、常见问题

**Q1：点录音没反应 / 提示缺东西？**
要先确保装好了录音组件。在命令行运行：
```
python -m pip install sounddevice
```
还要确认电脑**有麦克风**且系统允许程序使用麦克风。

**Q2：打开窗口提示缺 PyQt5？**
```
python -m pip install pyqt5
```

**Q3：网页版打不开？**
确认你运行的是 `python app/webui.py`，然后浏览器访问 `http://127.0.0.1:8012`。如果还是不行，先装：
```
python -m pip install fastapi uvicorn
```

**Q4：识别出来的音符有点乱？**
- 换 `small` 模型（更准）。
- 保持「降噪开启」。
- 唱得清楚、音量平稳、环境安静些。

**Q5：没有内置样例可选？**
内置音频要先生成一次。在命令行运行：
```
python gen_classic_melodies.py
```
它会自动生成 144 个示例音频，稍等片刻即可。

**Q6：保存的 Markdown 在哪？**
默认在 `melody2score\app\exports\` 文件夹里，文件名是「你起的名字 + 时间」。

**Q7：网页版录音只能录 5 秒，想录长一点？**
网页版目前固定录音时长，想自由控制时长请用**图形窗口版**（GUI），那里可选 3/10/30/60 秒。
