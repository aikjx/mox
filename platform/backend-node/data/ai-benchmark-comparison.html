🔍 诚信声明 · 独立复现指南（禁止欺骗 / 禁止骗分 · 7 条铁律）

  • 1 · 真实 LLM：报告由本机环境变量 DEEPSEEK_API_KEY 尾号 f45354 的真实 DeepSeek API 生成，没有使用 _generateIntelligentResponse local 假引擎。脚本缺少 Key 会 FATAL EXIT 1 拒绝骗分。
  • 2 · 严格单次：每道题 = AIEngineCore process() / executeCapability('reasoning') 严格调用 一次，无 retry，无 fallback 降级。实际 degraded=true 会在「降级」列单独标记，本题 30/30 均为 false。
  • 3 · 答案留痕：每条答案 SHA-256 写在 data/ai_benchmark_results.json，results[].answer_text 原文可独立 Hash 校验匹配；评分函数 scoreAnswer() 纯正则/数字/JSON Schema，100% 可手动逐条复核。
  • 4 · 时效性 TODAY 固定：参考基准 = 2026-08-23（来自系统上下文注入，不是模型记忆）。其他日期重跑，请修改 reference_answer.value。
  • 5 · 独立复现命令（≈ 5~8 分钟，需等 Reasoning 类题）：
    cd platform/backend-node && set DEEPSEEK_API_KEY=sk-**********f45354 && node test/ai-engine-real-benchmark.js
  • 6 · 离线评分复核（不用调用 AI）：打开 data/ai_benchmark_results.json，任取一条的 answer_text 对照 reference 手动判分；如发现任何一题 strict=false 但表中标记通过 → 本报告立即作废。
  • 7 · 四端点对齐：脚本 require(src/ai-engine-core.js) = 后端 routes/ai-engine.js 同一类。getCapabilities() → GET /ai/engine/capabilities，process() → POST /process，executeCapability('reasoning') → POST /analyze，metrics → GET /metrics，完全同入口，0 旁路。
