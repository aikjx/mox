# MOX 全局错误码系统

企业级统一错误码体系，覆盖所有业务域。

## 错误码规范

```
┌────┬────┬────────┐
│ KG │ 01 │ 001    │
├────┼────┼────────┤
│ 域  │ 模块│ 序号  │
└────┴────┴────────┘
```

- **域代码**（2位字母）：业务域标识
- **模块代码**（2位数字）：域内模块编号
- **错误序号**（3位数字）：具体错误编号

## 域代码表

| 域代码 | 业务域 | 范围 |
|--------|--------|------|
| `KG` | 知识图谱 | KG000001 - KG999999 |
| `AI` | AI 能力 | AI000001 - AI999999 |
| `FL` | 工作流 | FL000001 - FL999999 |
| `OP` | 算子引擎 | OP000001 - OP999999 |
| `PJ` | 项目管理 | PJ000001 - PJ999999 |
| `RS` | 资源中心 | RS000001 - RS999999 |
| `US` | 用户/权限 | US000001 - US999999 |
| `PL` | 平台/系统 | PL000001 - PL999999 |
| `DT` | 数据处理 | DT000001 - DT999999 |
| `CL` | 云存储 | CL000001 - CL999999 |

## HTTP 状态码映射

| 错误类型 | HTTP 状态码 | 说明 |
|----------|------------|------|
| 400 Bad Request | 400 | 参数校验失败、请求格式错误 |
| 401 Unauthorized | 401 | 未认证、Token 无效 |
| 403 Forbidden | 403 | 无权限、访问被拒绝 |
| 404 Not Found | 404 | 资源不存在 |
| 409 Conflict | 409 | 资源冲突、重复创建 |
| 422 Unprocessable | 422 | 业务规则校验失败 |
| 429 Too Many Requests | 429 | 限流、频率超限 |
| 500 Internal Server Error | 500 | 系统内部错误 |
| 503 Service Unavailable | 503 | 服务不可用、下游故障 |
